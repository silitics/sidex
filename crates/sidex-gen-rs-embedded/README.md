# Sidex: Rust Code Generation for Embedded Targets

This crate is part of [Sidex](https://oss.silitics.com/sidex/). It contains the `rust-embedded` code generator, which generates allocation-free Rust types for `no_std` targets from Sidex IR. The generated types use the [`sidex-embedded`](https://crates.io/crates/sidex-embedded) runtime.
